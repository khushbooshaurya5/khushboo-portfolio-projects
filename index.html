Semiconductor Defect-Detection Pipeline

Research Question
Can surface features from microscope imagery predict defects on semiconductor production mirrors reliably enough for engineers to trust?
Approach
An end-to-end pipeline (built from scratch) ingesting HDF5 microscope images, extracting six features per measurement point and linking them to WLI surface-roughness and defect labels. Image-processing and computer-vision algorithms handled pixel mapping; a per-collector dx/dy grid search with polar-to-pixel conversion and statistical pixel-offset detection fixed a coordinate mismatch, feeding a Random Forest classifier.
Contribution
Reported honestly that severity prediction did not work — and shipped a modular Tkinter image-processing frontend (plugin architecture, HDF5 / ORF / PNG inputs, YAML-based config, logging with file & stdout redirection, pyinstaller executables) so engineers could run analyses themselves.
