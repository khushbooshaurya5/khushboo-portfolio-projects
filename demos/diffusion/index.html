2D Diffusion — watch it denoise

A generative model, live in your browser. A tiny denoising diffusion model (PyTorch, DDPM) learned to turn pure Gaussian noise into a target distribution. Press a shape and watch 1,600 particles run the reverse process — 200 denoising steps, each one a real neural-net inference via ONNX — until the noise resolves into the shape. One class-conditional model draws all four.
